# Instala los modulos con npm i

# Sigue estrictamente estos pasos para realizar tu entrega:

1. Arriba a la derecha, hagan clic en el botón que dice Fork.
2. Haz clic en Create fork. Esto creará una copia exacta de mi proyecto en tu propia cuenta de GitHub.
3. Ve a la copia del proyecto que ahora está en tu perfil, y clónalo
4. Abre la terminal dentro de la carpeta del proyecto y muévete a una nueva rama con tu nombre (reemplaza apellido-nombre con tus datos en minúsculas y sin espacios): `git checkout -b entrega/apellido-nombre`
5. Modifica el código correspondiente, ejecuta tus pruebas y guarden tu avance localmente 
      - git add . 
      - git commit -m "Entrega de category-ms de [Tu Nombre]"
6. Publica tu rama en tu servidor `git push -u origin entrega/apellido-nombre`
7. Entra a tu repositorio en la página de GitHub. Verás un botón verde arriba que dice Compare & pull request. Haz clic ahí. Asegurate de que la base apunte a mi repositorio original y haz clic en Create pull request.
